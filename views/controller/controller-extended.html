Overlay Visibility Shows or hides each overlay everywhere it's in use, both in OBS browser sources and Desktop Mode windows. Hiding an overlay doesn't close its Desktop Mode window; the window just goes empty. This setting is saved, so a hidden overlay stays hidden after a restart. Lap Timer, Pit Timer, Fastest Lap and Message Box aren't listed here: they show up by themselves when there's something to show (Lap Timer's visibility is set in its own section).

Weather Options

Automatic uses the temperature unit set in the game. Celsius or Fahrenheit always use that unit, whatever the game is set to.
Shows or hides the Weather Forecast rows.
During the Formation Lap, shows the Weather overlay for about 12 seconds once the leader has driven around 10% of the lap, even if the overlay is currently hidden.
If the session has more than 4 forecast times, shows all of them by switching to the next set every 10 seconds. When off, only the first 4 are shown.
Forecast Session: --
If more than one session is left in the Race Weekend, you can choose which session's forecast to show. Use Previous/Next Session to move between them, or Current Session to jump back to the session you're in.

Live Speed Options

Shows the driver's name and the team color line in their team's color. The color comes from the game, or from OverridePrimaryColor in public/data/DefaultTeams.json if you've set one there. When off, both are white.

Pit Timer Options

Shows the pit stop timer, and the background behind the team logo, in the team's color. The color comes from the game, or from OverridePrimaryColor in public/data/DefaultTeams.json if you've set one there. When off, the timer is white and the logo background is the original dark blue.

Pit Window Options

Automatically hides the Pit Window overlay after a set time (see Display Duration), whether it was shown from Overlay Visibility or popped up by itself. It also has to be on for Automatic Mode to work. When off, the overlay stays visible until you hide it.
How long the overlay stays on screen before hiding again, while Automatic Display is on. Default is 15 seconds.
When the overlay pops up by itself, based on the game's pit window. Needs Automatic Display to be on.
None: never pops up.
1 Lap Before Window: on the lap before the pit window opens.
On Pit Window: on the lap the pit window opens.
Both: on both of those laps.

Car Damage Options

Shows the driver's name in their team's color. The color comes from the game, or from OverridePrimaryColor in public/data/DefaultTeams.json if you've set one there. When off, the name is white.
When on, each tyre shows how much life it has left (a new tyre shows 100%). When off, it shows how worn the tyre is (a new tyre shows 0%).
Automatically hides the Car Damage overlay after a set time (see Display Duration), whether it was shown from Overlay Visibility or popped up by itself. It also has to be on for Auto-Popup to work. When off, the overlay stays visible until you hide it.
How long the overlay stays on screen before hiding again, while Automatic Display is on. Default is 15 seconds.
When the overlay pops up by itself. Needs Automatic Display to be on.
Never: never pops up.
On Car Damage: when a car part (wings, floor, sidepods, diffuser, brakes, engine or gearbox) first gets damaged enough to turn yellow. Tyre wear doesn't count.
On Any Damage: the same, plus every 5% of wear on your most worn tyre.

Lap Timer Options

The Lap Timer has no Overlay Visibility button, so its visibility is set here.
Always Off: never shown.
Automatic: shows by itself while you're on track. In Practice and Qualifying it appears for the last 10% of your out lap and stays until you're back in the garage. In a Race it shows all the time, except in the garage and during the Formation Lap. In Time Trial it shows whenever you're out of the garage.
Always On: always shown.
Which lap your times are compared against in Time Trial.
Player Session Best: your best lap in this session.
Personal Best: your personal best on this track.
Rival: your rival's lap.
If there's no time for the chosen option yet, the comparison stays empty.
Who your times are compared against in Q1/Q2 and Sprint Qualifying SQ1/SQ2. Other qualifying sessions always compare to the leader.
Default: if you're safe from elimination, you're compared to the leader. If you're in the knockout zone, you're compared to the driver in the last safe position, or to the leader if that driver has no time yet.
Always Leader: always compared to the leader.
Which lap your times are compared against in a Race.
Fastest Lap: the fastest lap of the race so far, by any driver.
Personal Best: your own best lap of the race.
Last Lap: your previous lap.

Speedometer Options

Switches the Speedometer between two looks: the F1TV broadcast style, or the MultiViewer style. With 2026 cars, the DRS indicator automatically becomes Overtake Mode (OT) in both.
Automatic uses the speed unit set in the game. Always KMH or Always MPH use that unit, whatever the game is set to.

Leaderboard Options These options apply to both Leaderboard versions (Initials and Last Name). Options marked [Race] only make a difference during Race sessions, and [Non-Race] options only in all other sessions. Options without a mark work in every session. The example images show the Initials version; the Last Name version behaves the same.

MFD Page:
Swaps the timing column for other info about each driver.
Off: the default timing display.
MFD1: current tyre compound.
MFD2: current tyre age (in completed laps).
MFD3: laps completed (outside of races), or number of pit stops / tyre changes (in races).
MFD4: positions gained or lost (races only).
Pane:
Sets how much of the Leaderboard is shown.
Full: the default. Full width and height, shows everything.
Narrow: full height but narrower, without the timing column.
Short: full width, but only the session part at the top (session name, timer and any banners).
Narrow+Short: the session part at its smallest (narrow and short).
Logo: only the series logo (F1 or F2), everything else hidden.
Standings:
Replaces the Leaderboard with championship standings.
Off: the normal Leaderboard.
Drivers: Drivers' Championship, from public/data/DriverStandings.json.
Constructors: Constructors' Championship, from public/data/ConstructorStandings.json.
The game doesn't send standings, so edit those files to fill in your own.
Shows the Drivers' and Constructors' standings during the Formation Lap, if Standings isn't already turned on above. Drivers' standings show while the leader is roughly 25–60% into the lap, followed by Constructors' standings until the leader is about 80% through.
Standings Driver Count:
How many drivers the Drivers' standings show. The panel's height adjusts to match. If the standings file has fewer drivers than this (e.g. 16), the rest is left as empty space at the bottom. If it has more (e.g. 26 with this set to 24), the extra ones aren't shown.
Standings Team Count:
How many teams the Constructors' standings show. The panel's height adjusts to match. If the standings file has fewer teams than this, the rest is left as empty space at the bottom. If it has more, the extra ones aren't shown.
Shows only the session part (the Short pane) until the leader completes Lap 1 of the race.
Shows the drivers' names in full width. The timing column is hidden while this is on.
Shows each driver's number instead of their team logo.
Shows each driver's gap to the race leader. When off, it shows the interval (gap to the car ahead).
Shows each driver's fastest lap time of the session. When off, only P1 shows a lap time and everyone else shows their gap to it.
Highlights the active driver: a white background with their full name.
A more subtle highlight for the active driver: just a team-colored bar next to their row.
Highlights the active driver's teammate (if they have one), in the same style as the Primary Player Indicator.
Shows an indicator on the left of the Leaderboard when a driver has DRS active (pre-2026 F1 cars and all F2 cars) or Overtake Mode active (2026 F1 cars).
Shows each driver's battery level during a race, when the game provides it.
Shows each driver's total penalty time, when they have any. Unserved stop-and-go penalties count as 10s each, and an unserved drive-through shows as DT.
Adds an extra background behind the position numbers column.

Driver Name Options

Display Variant:
Picks which version of the overlay is shown while it's switched on. Some versions only work in certain sessions; if the one you picked can't be shown right now, Player Name is shown instead.
Player Name: the driver's number. Works in every session.
Race Leader: races only, while the driver is P1.
Race Story: races only. Starting position compared to the current one.
Best Lap Time: outside of races. The driver's best lap and the tyre it was set on.
Chasing Driver Ahead: races only. Shows who the driver is chasing; switches to Race Leader at P1.
In the Player Name version, shows the driver's number as an image, if one exists for that driver. When off, or if no image is found, the number is shown as text.
Hides the overlay automatically after about 15 seconds. It comes back when you pick a different Display Variant, switch the overlay off and on again in Overlay Visibility, or turn this option off.

Session Info Options

Toggle: simple on/off. The overlay is shown or hidden only with its Overlay Visibility button, with no automatic hiding.
Automatic: when switched on, the overlay shows for 10 seconds, then hides. To show it again, switch it off and on again in Overlay Visibility.
Controlled: the overlay shows for 10 seconds at the start of every session, then hides. It has to be switched on in Overlay Visibility for this to work.

Message Box Options

Halves how long each message stays on screen. Useful in busy sessions with lots of messages, such as Multiplayer.

Custom Overlays Your own overlays, made by you or shared by others. Put them in the views/custom/ folder (see the README there), then press Refresh to list new ones here. Each overlay gets a Visible toggle, plus any settings its creator added. "Telemetry Example" is a sample to copy and start from.
